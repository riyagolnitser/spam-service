# Error Analysis

На изолированном тестовом наборе модель не допустила ложноположительных срабатываний: все 757 ham-писем были корректно классифицированы как ham.

При этом 19 из 269 spam-писем были пропущены. Это осознанный компромисс: для антиспама цена FP выше цены FN, поэтому порог выбран так, чтобы максимизировать Precision(spam) при Recall >= 0.90.

## Возможные причины пропусков

- Спам-письма с коротким или нехарактерным текстом.
- Письма, маскирующиеся под обычную переписку.
- Недостаточное количество похожих примеров в train.
- Ограничение TF-IDF: модель плохо обобщает новые формулировки без совпадающих слов и биграмм.

## Возможные улучшения

- Добавить символьные n-граммы.
- Использовать градиентный бустинг поверх TF-IDF.
- Добавить эмбеддинги трансформера.
- Расширить датасет свежими примерами спама.
